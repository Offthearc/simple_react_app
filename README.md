# simple_react_app

A minimal React application with routing and component structure, built with Vite and TypeScript.

## Prerequisites

- Node.js 18+
- npm

## Setup

```bash
git clone git@github.com:Offthearc/simple_react_app.git
cd simple_react_app
npm install
```

## Run dev server

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Run tests

```bash
npm test -- --run
```

## Lint

```bash
npm run lint
```

## Build

```bash
npm run build
```
